Herramientas de desarrollo de software

El taller del programador: editor, versiones y terminal sin fricción.

>_ En qué consiste

Un oficio se ejecuta bien cuando las herramientas dejan de estorbar. Esta área pone a punto el entorno de trabajo: editor afinado, control de versiones en orden y terminal bajo control.

Y hay una regla de oro del taller: lo que funciona se respalda con versiones y se documenta. Cuando el código se rompe (y se romperá), Git es la diferencia entre reparar en un clic o reescribir una semana.

>_ Lo que se estudia

Los puntos centrales del área en la ruta de la Orden.

  • Editor de código (VS Code): extensiones mínimas, atajos y formateo
  • Git esencial: init, add, commit, log y ramas básicas
  • GitHub y portafolio público: los commits cuentan la historia
  • Terminal esencial de Windows y Linux: moverse, crear y ejecutar con criterio
  • Depurador y consola del navegador: ver qué pasa por dentro
  • README de una página: qué hace el proyecto, cómo se ejecuta y qué falta

>_ Cómo la practicamos

Con el método de la Orden: nada se aprende solo leyendo.

[01] Entorno a medida

Configurar el editor con extensiones mínimas y un formateador común para el grupo.

[02] Primer repositorio

Proyecto con historial limpio: commits que explican qué cambió y por qué.

[03] Rutina de taller

Commit al final de cada sesión de código: el avance se respalda, no se confía a la suerte.
