Desarrollo de entornos web

Páginas que funcionan desde cero: estructura, estilo y comportamiento.

>_ En qué consiste

La web es el medio donde más ideas se publican hoy. Esta área construye desde la base —HTML para la estructura, CSS para el estilo, JavaScript para el comportamiento— sin escalones mágicos: los frameworks llegan cuando se entiende el piso.

La prueba más directa está a la vista: esta misma web del grupo es práctica del área. Cada página que construyes se abre, se usa y se critica en el navegador, sin rodeos.

>_ Lo que se estudia

Los puntos centrales del área en la ruta de la Orden.

  • HTML semántico: estructura con significado, no divs a lo loco
  • Formularios y validación básica del lado del cliente
  • CSS: selectores, modelo de caja, colores y tipografía
  • Diseño responsivo: flex y grid con criterio
  • JavaScript: DOM, eventos y lógica que atiende al usuario
  • Accesibilidad y rendimiento: la web del grupo, navegable para todos

>_ Cómo la practicamos

Con el método de la Orden: nada se aprende solo leyendo.

[01] Mini sitio personal

Tu primer sitio con HTML y CSS: estructura limpia y estilo propio.

[02] Interacción real

Agregar JavaScript que haga algo útil: menú, formulario o búsqueda simple.

[03] Proyecto guiado

Evolucionar esta web del grupo: cada mejora se propone, se aprueba y se publica.
